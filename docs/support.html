QGIS · Sentinel-2 · GPR · Land Surface Phenology

Sentinel-2 biophysical retrieval, gap filling, and phenology analysis inside QGIS.

GEE GPR Phenology is a QGIS plugin that implements a complete workflow for Sentinel-2 BOA/L2A imagery, Gaussian Process Regression prediction, temporal gap filling, double-logistic fitting, and land surface phenology metrics.

QGIS Plugin page Report an issue

Core outputs

  • Biophysical variable rasters from Sentinel-2 reflectance
  • Temporally gap-filled image series
  • LSP metrics: SOS, EOS, POS, LOS and related parameters
  • PDF and CSV reports for reproducible outputs

Main features

Spectral GPR prediction

Estimates crop biophysical variables pixel by pixel from Sentinel-2 BOA/L2A reflectance using Gaussian Process Regression.

Temporal gap filling

Uses an RBF kernel to complete missing or cloudy observations and build consistent temporal raster series.

Phenology metrics

Fits double-logistic curves and derives land surface phenology metrics such as start, end, peak and length of season.

QGIS integration

Automatically loads outputs into QGIS with organized layer groups, symbology, and PDF/CSV reporting.

Recommended workflow

  1. Define or draw an AOI in QGIS.
  2. Select Google Earth Engine or local Sentinel-2 BOA GeoTIFF input.
  3. Run spectral GPR prediction for the selected biophysical variable.
  4. Apply temporal gap filling to obtain a continuous time series.
  5. Generate LSP metrics and export maps, CSV summaries, and PDF reports.

Scientific basis and attribution

This plugin is a Python/QGIS implementation developed from the ideas, mathematical workflow, and visualization logic of a previous Google Earth Engine JavaScript methodology. It is not only a literal adaptation: it includes QGIS Processing integration, multilingual support, reporting, local GeoTIFF workflows, metadata/security fixes, and repository-ready packaging.

Support and issue tracking
